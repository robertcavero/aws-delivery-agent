## Tecnologias Utilizadas
- Amazon Bedrock
- Amazon Step-Functions
- Modelo Amazon Nova Lite


## Objetivo do Projeto
- Abordar a utilização de AI Agents na automatização de tarefas repetitivas.
- Demonstrar familiaridade com a plataforma AWS.
- Promover uma solução digital para negócios.


## Como o programa funciona?
- O programa recebe a entrada "pedido" em formato JSON.
- O modelo extrai as informações relevantes do pedido e as organiza.
- Ao extrair o endereço de entrega, determina a rota mais eficiente e a retorna.
